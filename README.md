# .github

synmm のアカウント全体で使う既定の issue テンプレート。自分の `.github/ISSUE_TEMPLATE/` を持たない repo で使われる。

| テンプレート | Type | 使うとき |
|---|---|---|
| Task | Task | やることが決まっている作業 |
| Feature | Feature | 新しい機能・やりたいこと |
| Bug | Bug | 意図しない動き |
| Research | Research | 問いに答える・選択肢から選ぶ（完了条件は結論が出ること） |
| List | List | 溜めて見返す常駐リスト（欲しい物・出品するものなど。close せずに使い続ける） |

- どのテンプレートも Project #1（`synmm/1`）に自動で追加する。label は使わない
- 白紙の issue は作れない（Type が付かず Project にも入らないため）
